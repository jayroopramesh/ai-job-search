- Valid, non-expired government photo ID with full name
- Alone in the room; face visible and well-lit throughout
- Single monitor only; connected to power
- All other apps/tabs closed — **one extra browser tab allowed for syntax
  reference only** (web searches for syntax OK; searching for answers is not)
- No other devices (phone/tablet), no screenshots/printing/downloading
- No writing/executing code in the browser dev console
- **No AI tools** (no Claude/Copilot/ChatGPT during the test)
- Scratch paper **is** allowed
- Unstable connection or interrupted video/audio/screen-share → redirected to
  proctoring setup (time keeps running — stabilize network beforehand)
