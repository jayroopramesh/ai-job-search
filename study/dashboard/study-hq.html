  1. AUS Entropy. H(t) = −Σ p(i|t) log₂ p(i|t) — each term is "how surprising class i is" times "how often it happens"; the minus sign is there because log₂ of a fraction is negative. (a) Half-and-half node vs an all-one-class node — bigger H, and which gives zero? (b) Picking a split, is the tree driving H up or down in the children? (c) Gain = H(parent) − Σ (Nj/N) H(childj) — what is the Nj/N doing, and what breaks without it? ~3 min
  2. OXFORD L1 vs L2, by the derivative. d(e²)/de = 2e. d|e|/de = sign(e) — flat, ±1. That derivative is the pull the point exerts on the fit. One point sits far out: under which loss does it drag the fit further? Answer via the derivative, not the noise model. Then finish — "heavy-tailed noise model means the loss treats a big residual as ___." ~90 sec
  3. AUS Lazy learner. A tree does its work before any query arrives; KNN does its work when the query arrives. Ten million rows, answer needed in milliseconds, per query — which is in trouble, and name the step that costs. Then: KNN's training is listed as "fast, no explicit learning step." Is that an advantage? Say what it actually means. ~90 sec
  4. OXFORD Vanishing gradients. ∂L/∂h₁ = ∂L/∂hn · Π ∂hk+1/∂hk — the gradient reaching an early layer is everything downstream multiplied together. (a) Each factor slightly below 1: what happens to the product as depth grows, and to the early layers? (b) Residual block hl+1 = hl + f(hl), so ∂hl+1/∂hl = I + ∂f/∂hl — what is the I doing inside that product? (c) The deck says unravelling a residual net shows the output is the input plus a sum of smaller networks. Connect that to (b). ~4 min
  5. AUS Naive Bayes. Classify to the y maximising P(y) Πj P(xj|y). Posterior ∝ prior × likelihood; the Π is the naive part. (a) State what is assumed — not the name, the statement, in terms of features and class. (b) What does it buy? Think what you'd have to count without it. (c) Two features are near-duplicates: more confident posterior or less, and is that confidence earned? (d) It often classifies well while its probabilities are bad. How can both be true? ~4 min

How the tutor works

  • Spaced repetition — every tested fact climbs the ladder 1 → 3 → 7 → 14 → 30 days; a miss resets it to 1 day and raises a 🚩 flag. At 98 days the ladder finally runs to term, so items reach real long-term spacing instead of churning.
  • Flag-point attack — the 21:00 clinic hits every open flag from a format it has not seen yet; cleared only after 3 consecutive passes on different days and different formats.
  • Active recall first — new topics start with a pre-test before any teaching; material is never shown right before it's quizzed.
  • Interleaving — evening gauntlets mix both courses (never >2 same-course questions in a row) plus CV overlap.
  • Feynman — daily 60-second close-out teach-backs + weekly deep teach-back on Saturdays.
  • Drive-only — every answer cites deck + page; new Drive uploads are auto-ingested each morning.
